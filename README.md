# WashMate - Laundry Service

This is a simple responsive laundry service landing page that I made as an assignment during my MERN course. It is designed to show a laundry service website with a navbar, some information about the service, and a booking button.

## Features
- Navigation bar with links
- Hero section with a heading and description
- Laundry image
- Book a Service button
- Responsive design for different screen sizes
- Hover effects on links and button

## Technologies Used
- HTML
- CSS

## What I Learned
- Creating layouts using Flexbox
- Using CSS properties to style a webpage
- Adding hover effects
- Making a webpage responsive using media queries

## How to Run
1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in your browser.
